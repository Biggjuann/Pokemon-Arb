Add a search

Free text, exactly as you would type it into eBay. Comma separated for several at once — e.g. charizard vmax alt art, umbreon gold star.

A free-text search has no comp attached, so anything it finds is valued against whichever catalogued card the matcher can tie it to by card number. If nothing matches, the listing is ignored rather than guessed at.

Rebuild from the catalog

Re-derives targets from comps already synced — the top N most valuable cards in each set. No API calls, and targets you disabled stay disabled.

Negative keywords

A listing whose title contains any enabled term is dropped before it is stored or valued. Case insensitive, matched as a substring. Proxies, lots, non-English prints and graded slabs are already rejected without needing a keyword — use this for what your own searches keep dragging in.
